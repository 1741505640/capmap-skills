# capmap-scheme — 写 / 改方案

原则：[capmap-system](../capmap-system/SKILL.md) · Tag：[status-tags](../capmap-system/reference/status-tags.md)

## 启动

1. 读 `.agents/skills/capmap-system/capmap.yaml` → `docs_root`
2. 无配置 → 先 [capmap-init](../capmap-init/SKILL.md) 或询问用户

## 硬规则

1. 路径：`<docs_root>/方案/<主题>/<方案标题>.md`（活跃方案禁止留在 `_archive`）
2. 必须有 **`## 变更记录`**
3. 大改方向：仅 `方案中` 可自由改；`已确认` 及之后大改 → 开 Vn（实现期小修正可 append 变更记录）
4. 文首链底图；底图 §0 挂进行中方案
5. 文首 YAML：`方案` + **一个**主状态：  
   `方案中` → `已确认` → `开发中` → `已开发` → `验证中` → `已验证` → `落地中` → `已落地`（归档前）→ 归档后 `已归档`  
   **禁止跳步**（尤其未验证不得已落地），见 [status-tags](../capmap-system/reference/status-tags.md)
6. **开干编码**时方案改为 `开发中`（不要只改底图）
7. 能力底图**不要**加 `状态/*` Tag
8. 不在此阶段归档（除非用户同时要求）
9. **写完 / 改完方案后必须走「待确认反问」**（见下节）；在用户确认共识之前：禁止标 `已确认`、禁止暗示可以开干编码、禁止擅自把待确认当成已决写入正文定案
10. **禁止**在方案阶段或开发未测时标 `已落地`

### 已归档后再改需求 → 开 Vn

基线留 `_archive` 且 `状态/已归档`；新建 Vn 为 `方案中`；底图 §1 可新增能力行（正文状态列，非 YAML Tag）。

## 待确认反问（grilling）

参考 grilling：把方案里的未决点当成**设计树**，按轮追问到共识，再落笔。

### 何时触发

- 新建方案写完首稿后（默认仍为 `方案中`）
- 方向微调改正文后，若仍有未决点
- 用户说「确认一下」「评审」「开干前过一遍」等

### 怎么做

1. **抽取待确认点**（事实自己查，决策问用户）：范围边界、取舍、不做项、接口/数据假设、验收标准、与既有能力冲突等。可在方案中维护 `## 待确认`（可选），但反问不依赖用户先写好该节。
2. **按轮推进**：每一轮只问当前 **frontier**（前置已决、现在就能答的问题）。一轮内问题编号列出，**等用户答完再开下一轮**。依赖本轮答案的问题留给后续轮。
3. **单题格式**（必须带推荐项）：

```
❓ **Q1** - **<题目标题>**：题干（可含选项 A/B/C）

➡️ <你的推荐答案与一句理由>
```

4. **事实 vs 决策**：环境/代码/仓库里能查到的事实 → Agent 自查（可并行），不要问用户；决策 → 必须反问并等待。
5. **收口**：frontier 为空、用户明确「就这样 / 确认 / 开干」后：
   - 把拍板写入 **`## 变更记录`**（触发可写「评审/grilling」）
   - 改正文中仍写着「待定」的段落
   - 删除或清空已决的 `## 待确认`
   - 方案 Tag → **`状态/已确认`**（若用户只要改文案不升状态，听从用户）
6. **未收口前**：保持 `方案中`；可先保存草案，但回复里必须抛出本轮 grilling 问题，而不是只丢「方案写好了」。

### 与 grilling 的关系

- 不要求用户再说「grill me」；**capmap-scheme 写方案即默认带一轮以上反问**。
- 用户明确「先别问、只要草稿」→ 可跳过，但文首/回复注明「待确认未 grilling」；之后升 `已确认` 前仍须补问。

## Checklist

```
- [ ] 1. 解析 docs_root；确认主题与底图存在
- [ ] 2. 已归档目标 → 新建 Vn
- [ ] 3. 写/改方案正文 + ## 变更记录；文首回链底图；§0/索引更新
- [ ] 4. 方案仅一个合法主状态 Tag；底图无状态 Tag
- [ ] 5. 抽取待确认点 → grilling 分轮反问（带 ➡️ 推荐）→ 等用户答完
- [ ] 6. 共识后：变更记录落定案；正文去待定；Tag → 已确认（除非用户另定）
- [ ] 7. 提醒下一步：开干 → 开发中 → capmap-dev → capmap-test → capmap-norm → capmap-archive
```
