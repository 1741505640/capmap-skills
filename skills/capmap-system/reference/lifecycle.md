# 生命周期（闭环说明）

## 各阶段「产物是什么」

| 阶段 | 输入 | 产物 | 谁消费 |
|------|------|------|--------|
| 方案 | 需求/评审 | 方案 md + 变更记录 + **体量** | 开发、评审 |
| 规格（仅大） | 已确认 + 体量/大 | `切片/<方案stem>/<方案stem>-00-规格.md` | 拆分、执行 |
| 拆分（仅大） | 规格 | `切片/<方案stem>/<方案stem>-NN-*.md` + DAG | gate、多人并行 |
| 开发 | 小：已确认；大：已拆分 + 用户点名切片 | **代码** + 底图 §1/§2 + 方案 `开发中`→`已开发`（Agent 对照方案判定，不等待人测） | 测试、运维 |
| 测试 | 已开发 + 用户同意转测（或点名 test） | 拍 1：测试文计划+用例（结果可未测）+ `验证中`；拍 2：人测/免测 → `已验证` | 发布决策、回归 |
| 规范 | 稳定契约 | `规范/` + 方案 Tag `落地中`→`已落地` | 接入方、运维 |
| 归档 | 闭环结束的方案 | `_archive`（含切片目录）+ `已归档` | 考古 |
| 反补 | git 历史 | 底图 §4/§5（无状态 Tag） | 策展人 |

## 进度挂在哪

| 问题 | 看哪里 |
|------|--------|
| 哪些**方案**在开发 / 验证 / 落地？ | 方案文 `状态/*` |
| 大需求切到哪张票了？ | `切片/<方案stem>/` 下各文 `状态/*` + frontier |
| 某主题有哪些能力、代码在哪？ | 能力底图 §1 / §2 |
| 某次测试跑到哪了？ | 测试文 `测试中` / `已验证` |
| 未立项、下轮要接着干的下一句？ | 文档首页 `## Inbox · 未立项`（开干指令） |
| 正在修运行时报错、尝试几次了？ | 会话内走 `capmap-debug` 清单计数（不落状态 Tag） |

## 分支状态机

```text
                    ┌─【小】──────────────────────────────┐
方案中 → 已确认 ────┤                                     ├─→ 已开发 → 验证中 → … → 已归档
                    └─【大】→ 规格中 → 已拆分 → 开发中 ────┘
                                         │
                                    切片 DAG + frontier 并行
                                    （用户点名才开跑）
```

详情与 Tag 表：[status-tags](status-tags.md)。

### 硬约束：禁止跳步

- **验证门**：未 `已验证` 之前，**禁止** `落地中` / `已落地`。
- **大需求门**：未 `规格中`→`已拆分` 不得 `开发中`；未全切片 `已验收` 不得 `已开发`。
- **切片门**：交票须 Demo+自测；人确认才 `已验收`。
- `capmap-lint` 对违规报 `status_skip` 等 error。

## 典型顺序

### 小需求

1. `capmap-scheme`：grilling → **体量判断+询问** → `已确认` + `体量/小`  
2. 方案 → `开发中` → 编码 → Agent 对照方案判定 → `capmap-dev` → `已开发`  
3. **询问**是否转测试（勿静默结束）→ 用户同意后 `capmap-test` 拍 1 → 人测/免测拍 2 → `已验证` → `capmap-norm` → `capmap-archive`  
4. **禁止**编码完停成「请自测，测过再说已开发」；也禁止标完已开发不问下一步

### 大需求

1. `capmap-scheme` → `已确认` + `体量/大`  
2. `capmap-spec` → `规格中` →（人确认规格）  
3. `capmap-slice` → 落切片 + 推荐运行模式 → **停住** → `已拆分`  
4. 用户点名 → `capmap-gate` 循环（frontier / 开干 / 交票 / 人验）  
5. 全切片 `已验收` → `capmap-dev` → `已开发` → **询问**转测试 → test 拍 1 → 人测/免测拍 2 → norm → archive  

## 冻结与增量版本

方案进入 **`已归档`** 后正文冻结。新需求开 Vn（新文 `方案中`），基线不回迁。
